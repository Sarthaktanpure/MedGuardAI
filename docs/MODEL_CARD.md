# Model Card

This project is not shipping a real counterfeit-detection model yet.

## Current status

- No production ML model is trained in this scaffold.
- No accuracy, precision, recall, or F1 claims are made here.
- Any future metrics must come from real evaluation runs and must never be hardcoded.

## Planned direction

- Synthetic bootstrap data generation for early pipeline validation.
- PyTorch training and ONNX export in later phases.
- A real, curated dataset will be required before any production-grade accuracy claims are credible.
